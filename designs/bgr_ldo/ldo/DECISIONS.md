## D-001. EA 입력 극성 — NMOS → **PMOS 확정**

**판정일**: 2026-07 | **상태**: 확정 | **영향**: Task 3 전체, Task 2 전류 예산

### 근거 측정 (`ldo/icm_chk.sp`)
조건: **ss / −40 °C / L=2 µm / W=10 µm / nf=1 / 기본 geometry**

| 소자 | 조건 | `[vth]` | `[id]` |
| :--- | :--- | ---: | ---: |
| nfet | V_SB = 0 | **0.9055890 V** | 32.80 µA @V_GS 1.2 / V_DS 1.0 |
| nfet | V_SB = 0.15 V | **0.9655977 V** | — |
| pfet | V_SB = 0 | **1.191607 V** | 90.80 µA @V_SG 2.1 / V_SD 1.0 |

파생: 바디효과 **+60.0 mV @V_SB 0.15 V** → **γ = 0.703 V^0.5** (2φ_F = 0.7 가정).
A1/A2 앵커 역산치 0.713과 정합. tt/27 대비 (ss + −40 °C) 기여 = **+108 mV**.

### 자기일관 해
V_SB는 독립변수가 아니라 tail 노드 전압이므로 반복 수렴시켜야 한다.

V_tail = V_ICM − V_th0 − γ(√(2φ_F + V_tail) − √(2φ_F)) − V_ov,in ,  V_ICM = 1.2 V 고정

| 입력쌍 반전 정도 | V_ov,in | V_tail 수렴값 | 단순 tail(0.10~0.15) | 캐스코드 tail(0.20~0.30) |
| :--- | ---: | ---: | :--- | :--- |
| moderate (gm/Id≈16) | ~50 mV | **0.175 V** | 마진 25~75 mV | **실패** |
| weak (gm/Id≈20) | ~0 | **0.211 V** | 마진 61~111 mV | **실패** |

### 극성 판정
| | 조건식 | 실측 대입 (VDD 3.3, V_ICM 1.2) | 마진 |
| :--- | :--- | :--- | ---: |
| NMOS 입력 | V_ICM ≥ V_th,n + V_ov,in + V_ov,tail | 1.2 ≥ 0.966+0.05+0.15 = 1.166 | **34 mV** |
| PMOS 입력 | V_ICM ≤ VDD − \|V_th,p\| − V_ov,in − V_ov,tail | 1.2 ≤ 3.3−1.192−0.05−0.15 = 1.908 | **708 mV** |

### ★ 폐기된 근거 — 이 항목의 핵심
NMOS 입력을 선택했던 원래 논리:

> "EA 출력이 pass 게이트를 구동하므로 2.0~3.3 V 상단 스윙 필요 → PMOS cascode 출력이 상단에 유리 → NMOS 입력"

**이 논리는 틀렸다.** folded cascode의 출력 스윙은 **출력단 캐스코드 미러가 정하며 입력 극성과 무관**하다.
두 극성 모두 출력단이 위쪽 PMOS 캐스코드 / 아래쪽 NMOS 캐스코드이므로
출력 범위 = **[2·V_dsat,n , VDD − 2·V_dsat,p]** 로 동일하다.
(차이는 어느 쪽이 미러이고 어느 쪽이 폴딩 브랜치의 캐스코드인가일 뿐)

실제로 입력 극성을 정하는 유일한 조건은 **V_ICM 헤드룸**이다.
thick-ox V_th가 0.9~1.2 V인 공정에서 V_ICM = 1.2 V는 3.3 V mid-rail(1.65 V)보다 아래이므로
**처음부터 PMOS 입력 영역이었다.**

### 부수 이점
1. **tail 캐스코드 가능** — PMOS 입력쌍 소스 노드 = 1.2 + 1.192 + 0.05 = **2.44 V**, VDD까지 0.86 V 여유.
   캐스코드(0.30 V) 써도 마진 560 mV. **tail의 r_o가 PSRR에 직결**되므로 실질적 이점.
2. **바디효과 없음** — 자체 nwell에 벌크를 소스로 묶으면 V_SB = 0.
   NMOS로 같은 효과를 내려면 딥엔웰이 필요하고 인클로저 룰 면적 벌금이 크다.
3. **1/f 노이즈 낮음** (2차 효과 — BGR이 지배하므로)
4. **LUT 안에 머문다** — `nfet_01v8` 입력쌍 대안의 별도 스윕(14분) 불필요

### 인정한 반대 논거
NMOS tail은 접지(조용), PMOS tail은 VAPWR(리플)에 붙으므로 **원리상 NMOS가 PSRR 유리**.
그러나 PMOS는 캐스코드 가능·NMOS는 헤드룸상 불가이므로 (캐스코드 시 유효 r_o ≈ g_m r_o²) 실질 역전.

### 이력
- `00_인계_통합.md` 원본은 "PMOS 입력"이었으나 **근거가 위 폐기 논리**였다 → 결론만 우연히 맞음
- LDO 시작 프롬프트가 "NMOS 입력 확정"으로 바꿈 → 본 판정으로 되돌림, **근거는 실측으로 교체**
- 사전 위험 제기(LDO 채팅 E1)는 방향이 맞았고 크기는 75~105 mV 비관적이었다

## D-002. R_on ≈ 52 Ω / dropout 200~300 mV — **폐기**

**상태**: 폐기 | **대체**: Step 1.5 삼극관 LUT 조회로 재산출

`k'_p ≈ 30 µA/V²`, W/L = 800, |V_th| = 1.0 V 가정의 **손계산**. 코너·온도·추출법 미기재로 규율 5 위반.

**폐기의 결정적 사유**: 같은 손계산 모델이 이 프로젝트에서 **vdsat을 2배 틀렸다**
(예측 0.59 V vs 실측 0.283 V @3 mA, W400/L0.5/VSG 1.3/VSD 1.5/tt/27).
국소 I-V는 맞췄으나 그 내부 분해(문턱 + 이동도 저하)가 틀린 전형이다.

파생 폐기: `00 §4.1`의 dropout ≤ 200 mV, LDO 시작문서 §6.1의 < 300 mV **둘 다 무효**.

## D-003. C_out 소자 — MOS cap **기각**, MiM 적층 채택

**상태**: 확정 | **영향**: Task 2 면적↔C_out 환산 전면 재계산

### 기각 사유 — 정격 충돌
thin-ox MOS cap의 절대최대가 **~1.95 V**인데 우리 오버슈트 하드 스펙이 **정확히 1.95 V**다.
즉 스펙 위반 시 **디캡이 가장 먼저 죽는 소자**가 되는 구조. 설계적으로 나쁘다.

부수적으로, 흔히 쓰이는 8.5 fF/µm²는 thin-ox C_ox 교과서값(t_ox ≈ 4.1 nm)이며 **당세션 미실측**이다.
(참고로 thick-ox는 우리 실측에서 역산 가능: probe2 pfet W400/L0.5, 게이트 면적 200 µm²에
`cgg` 326 fF = 1.63 fF/µm² ≈ ⅔C_ox → **C_ox(thick-ox) ≈ 2.4 fF/µm²**)

### 채택 — MiM 적층
- `camimc`가 `cap_mim_m3_1`·`cap_mim_m3_2` **동일**(2.00e-15 F/µm² typ) → 동일 풋프린트 적층 시 **4.0 fF/µm²**
- 금속-절연체-금속이라 항복전압 여유가 크다 → 오버슈트 정격 문제 소멸
- **결정적: met3~met4 층이므로 액티브 회로 위에 얹을 수 있다.** 30 pF = 7,500 µm²의 금속 면적이나
  BGR(5,500) + LDO 회로 위에 겹치면 **실면적 벌금이 거의 없다**

### 주의 2건
- Cc/C_out 하판 아래에 스위칭 회로를 두면 보상·출력 노드에 직접 주입 → 배치 주의
- `cap_mim_m3_2`의 상판 `cap2m`이 met5 바로 아래 층 → **TT의 met5 금지와 간섭 없는지 확인 필요**
  (m3_1 단층만 쓰면 2.0 fF/µm²로 확실히 안전)

### 대체된 것
LDO 시작문서 §6.4의 "C_out 100 pF = 예산 84%" 표는 MOS cap 전제 → **폐기, 재계산 필요**.
MC 시 글로벌 **−11%(cap_low)가 안정도 최악 코너**이므로 PM 검증은 그 값으로.

## D-004. BGR 트림 창 — 대칭 ±7% → **비대칭 (38.9 ~ 44.4유닛)**

**상태**: 확정 | **영향**: BGR 트림 회로 사양, Task 3 V_ICM

실측 V_ref = 1.18659 V, MC ±3σ = ±6.6%, **목표는 1.2 V** (1.18659가 아님). R2 = 41유닛 기준:

| 칩 | V_ref (트림 전) | 필요 보정 | 필요 R2 |
| :--- | ---: | ---: | ---: |
| −3σ | 1.108 V | +8.28% | **44.4유닛** |
| 공칭 | 1.187 V | +1.13% | 41.5유닛 |
| +3σ | 1.265 V | −5.13% | **38.9유닛** |

필요 범위 = **38.9 ~ 44.4유닛 (폭 5.5, 중심 41.65)**.
"41유닛 ±7%" 대칭 설계는 38.13 ~ 43.87유닛이라 **상단이 0.53유닛(≈1.3%) 부족**.

**수정**: 고정부 38.13 → **38.9유닛**, 트림 세그먼트 총합 **5.5유닛**.
**목표가 실측 중앙이 아니라 1.2 V이므로 창이 비대칭이어야 한다**는 것이 핵심.

트림 후 V_ref = **1.2 V ± 2.6 mV** (LSB 양자화 ±0.22%) → **Task 3의 V_ICM = 1.2 V ± 3 mV**.

## D-005. ★ 트림 스위치 R_on 상한 — 50 Ω → **≤ 5 Ω** (TC 사유)

## D-006. 트림 스위치 배치 — R2 접지단, 레벨시프터 **불필요**

**상태**: 확정 | **근거**: BGR 넷리스트 실측

```
XR1  VBE8 ↔ net1     L=34.431     (PTAT 저항)
XR6  0 ↔ VBE1        L=244.537
XR7  0 ↔ net1        L=244.537
XR2  0 ↔ VREF_LOW    L=244.537    ← 트림 대상 (41유닛 = 121 k)
```
**세 대형 저항 모두 한 단자가 접지**이므로 R2의 접지 쪽 끝에 이진 가중 세그먼트를 두고 단락 가능.

- 트림 구간은 41유닛 중 5.5유닛(13.4%) → **최상단 전위 = 0.134 × 1.186 = 159 mV**
- V_GS(최악) = 1.8 − 0.159 = **1.64 V**, V_SB ≤ 0.16 V로 바디효과 거의 없음
- **thin-ox `nfet_01v8` 사용 가능** (V_DS·V_GS 모두 1.8 V 정격 안)

→ **1.8 V 디지털 직결로 충분. 레벨시프터 5개(~750 µm²)와 그 검증 부담 제거.**

배경: TT 디지털 도메인은 VDPWR = **1.8 V 고정**이다. 보드에서 3.3 V를 인가해도
TT 내부 로직을 거쳐 오므로 우리에게 도착하는 건 1.8 V CMOS다. 3.3 V 주입은 불가능.

## D-007. 부하 범위 — I_min 50.8 µA / I_max 4 mA

**상태**: 확정

### I_min은 선택이 아니라 유도값
피드백 분압기가 반드시 있어야 하고 그 전류가 곧 최소 부하다. 양쪽에서 조여진다:
- R 크게(I 작게) → 경부하 출력극 하강, PM 붕괴. 25 µA면 pass의 r_o도 2배·R_div도 2배가 되어
  **출력극이 545 kHz → 271 kHz로 절반**
- R 작게(I 크게) → I_Q 예산. 200 µA면 BGR(60 µA)보다 커진다

→ **25~100 µA가 창, 50 µA가 중앙.**
**R_a = 4유닛(11.8 k), R_b = 8유닛(23.6 k), 비 1.5 정확, I = 50.8 µA.** BGR 유닛저항 재사용.
분압기가 최소부하를 겸하므로 **별도 더미 부하 불필요** — 설계 의도의 증거.

### I_max는 선언이나 창이 좁다
- 크게: PDN 강하(10 mA면 VAPWR 50 mV → line reg 측정 오염), 열, gm 변동폭
- 작게: 데모 가치. 레퍼런스 devstdin은 **300 µA까지밖에 특성화하지 못했다**
- 2 mA로 줄여도 **안정도는 안 쉬워진다**(최악은 경부하 = I_min이 결정).
  pass 면적도 210 µm²만 절약 → C_out으로 돌려야 1.8 pF

**주의**: TT 아날로그 핀의 4 mA 제한은 **근거가 아니다.** 부하가 온칩이므로 무관하다.
실제 근거는 PDN·gm 변동폭·데모 가치의 절충.

## D-008. ★ 과도응답 물리 한계 — Task 2 목적함수 변경

**상태**: 확정 | **영향**: Task 2 전체

$$\Delta V_{droop} \approx \frac{I_{step}}{2\pi \cdot UGF \cdot C_{out}}$$

C_out = 30 pF, UGF = 10 MHz(공격적)에서 Z_peak = 530 Ω:

| 스텝 | 드룹 |
| :--- | ---: |
| 100 µA | 53 mV |
| 500 µA | 265 mV |
| **4 mA** | **2.1 V — 붕괴** |

**4 mA 고속 스텝은 온칩 캡만으로 물리적으로 불가능하다.**
외부 캡도 무용지물 — ua 경로 500 Ω × 1 µF의 코너가 318 Hz.

결함이 아니라 **capless + 소면적의 근본 한계**다. 상용 "capacitor-free"는 *안정도*에
외부 캡이 불필요하다는 뜻이지 과도까지 커버한다는 뜻이 아니다.

**대응**: 부하 슬루를 우리가 소유하므로 **스펙을 3단 계층화**(04 문서 참조).

### ★ Task 2 목적함수 (최종형)
> 면적 제약 하에서 **`C_out × UGF` 최대화**. 단
> (a) `C_gg ≤ 0.15 C_c` 극점 조건,
> (b) 슬루율 `(C_c + C_gg)/I_EA`가 오버슈트 < 1.95 V를 만족,
> (c) `C_c` 축소가 HF PSRR을 개선하나 LF PSRR·과도와 충돌하므로 주파수대별 분리 최적화,
> (d) C_out은 **MiM 적층(4.0 fF/µm²) + over-active 배치** 전제 (D-003).

원래 목적함수였던 "Cc 최소화"는 **대체됨**.

### 부수 확인 — HF PSRR과 Cc의 관계
HF에서 pass 게이트는 C_gs(→VAPWR)와 C_c + C_gd(→출력 = AC 접지)의 용량 분압으로 결정된다:

VAPWR 추종률 = C_gs / (C_gs + C_c + C_gd)

C_gs ≈ 200 fF 기준: C_c = 2 pF → 9%, C_c = 0.5 pF → **29%**.
추종률이 높을수록 V_SG가 일정해져 **HF PSRR 개선**.
→ **"Cc 축소 = HF PSRR 개선"이 성립.** Ahuja가 PSRR에 좋은 이유도 동일
(캐스코드가 게이트를 출력에서 격리해 VAPWR 추종을 방해하지 않음).

## D-009. pass device 상한 조건 추가 — C_gg ≤ 0.15 C_c

**상태**: 확정 | **영향**: Task 1 W 상한

2단 Miller의 극점 분리식에서 p₂ ∝ C_c/(C_c + C_gg).
C_gg ≤ 0.15 C_c면 p₂ 열화 13%로 합리적 기준.

C_c = 2 pF → **C_gg ≤ 300 fF** → 실측 326 fF인 **W=400은 이미 경계**.
→ Task 1은 W=400을 상한 근처로 보고 **아래로 탐색**해야 한다.

**C_gg의 진짜 역할은 극점이 아니라 EA 슬루율** `(C_c + C_gg)/I_EA`이며,
오버슈트 < 1.95 V 하드 스펙이 여기에 걸린다.

### 기존 제약 구조 (변경 없음)
- **C1 포화 유지(W 하한)** — vdsat 0.283 V @3 mA 실측으로 **binding 아님**
- **C2 게이트 드라이브** — folded cascode 출력 하한 ≈ 2·V_ov,n ≈ 0.5 V → V_SG 최대 ~2.5 V. 여유
- **C3 EA 출력 천장(W 상한)** — 경부하에서 V_SG(I_min) > 2·V_ov,p + 마진 필요.
  ff/125 °C에서 |V_th|가 0.55~0.6 V로 내려가면 마진 100~200 mV뿐
- **C4 OFF 능력/리키지(W 상한 2)** — I_D(V_SG=0.4 V, ff, 125 °C) ≤ 0.2 × I_min

→ **C1이 하한, C3/C4/C_gg가 상한.** 레이아웃은 **m × (W=10 핑거)** (LUT 정확도 + 정석).

## D-011. geometry 규약 — DC 무해, AC는 반영 필요

LUT는 `ad/as/pd/ps/nrd/nrs` **생략(PDK 기본값)** 으로 스윕되었고,
xschem은 BGR 넷리스트처럼 `ad=5.8 as=5.8 pd=40.58 ps=40.58 nrd=0.0145 nrs=0.0145`를 명시적으로 뱉는다.

**DC 영향은 작다** — BGR 실회로 교차검증(명시적 geometry)에서 ID 오차 −0.04 ~ +1.05%.
`nrd` 0.0145 sq는 확산 R_sheet ~120 Ω/sq 기준 1.7 Ω → 4 mA에서도 7 mV.

**그러나 AC/과도에서는 다르다.** `ad/as/pd/ps`는 접합 캡(C_db/C_sb)을 결정하며
**W = 400 µm급에서는 출력 노드 캡에 유의미하게 기여**한다.
→ Task 1의 C_gg 확정에는 무관하나, **Task 2 C_out 예산과 Task 4 극점 계산에는 반영.**
xschem이 W=400/nf=1에 대해 뱉는 실제 값을 넷리스트에서 확인할 것.

## D-014. thin-ox W — 이산 축, 보간 금지

## D-015. power-good 급전 레일 — VAPWR / thick-ox

## D-016. ★ 트림 스위치 사이징 재산출 — thin-ox LUT 실측 (D-005 대체)

## D-017. C_byp (2 pF, 잠정) — BGR-EA 신호 결합 억제

**상태**: 확정(메커니즘) / 값은 잠정 | **영향**: Task 3 EA 입력쌍 사이징과 연동

folded cascode 단일단 구동 시 LDO 피드백(V_inp)이 입력 PMOS(M1)를 소스팔로워로 흔들어
공통소스(V_tail)가 흔들리고, 이것이 반대쪽 입력 PMOS(M2)의 C_gs2를 타고 BGR 출력 노드

**해결**: V_inn에 C_byp를 달아 분압비 C_gs2/(C_gs2+C_byp)를 0.49→0.149로 낮춘다.
C_gs2 ≈ 358 fF 기준 C_byp = 2pF에서 **PM 41.4°→63.5° 회복**.

**부수효과**: BGR 고주파 노이즈 LPF, soft-start 보조(τ=R_out·C_byp≈248ns, 이것만으로
오버슈트<1.95V 하드스펙 충족 못 함 — Task 5 별도 soft-start 필요).

**주의**: C_gs2=358fF는 intrinsic 값일 가능성(D6 규약) — 실효값은 +W·C_GSO 보정 필요,
분압비 0.149→0.157(약 5% 저하)로 결론 불변. **C_byp는 Task 3 입력쌍 재사이징 시 함께

## D-018. `nf`/`m` 규약 정정 — 표기는 유지, 관계만 명시

**상태**: 확정 | **영향**: 문서 표기, Task 8 레이아웃 착수 시 실질 적용

기존 사양 표기 "m × (W=10 핑거)"가 용어와 파라미터를 혼용하고 있었다. 실측 확인:

- **게이트 저항에서 m과 nf는 동등**하다 (R_g는 핑거 폭으로 정해지고 병렬수가 m이든 nf든
  같게 나눈다). 초기 "R_g=12.9kΩ vs 8Ω, 1600배" 비교는 잘못된 대상(W=400/nf=1 단일소자)과의
  비교였다 — `m=40×(W=10,nf=1)`은 이미 `W=400,nf=40`과 R_g가 같다(§lut/README.md §9.8).
- **차이는 접합 용량뿐**: `m=4×(W=10,nf=1)` ad=11.6µm² vs `W=40,nf=4` ad=5.8µm² (정확히 절반,
  핑거는 확산 공유·m은 비공유).
- 우리 노드(pass 드레인=LDO 출력, MiM 30pF)에서 그 차이는 0.2%로 **무시 가능**.
- **LUT 정확도는 오히려 `m×(W=10,nf=1)`이 유리** — BSIM4가 핑거 폭(W/nf)으로 bin을
  고르므로 기준폭에 정확히 안착한다.

**결론**: 현재 스키매틱(`m` 위주, `nf=1`)을 전기적 이유로 다시 그릴 필요 없음.
`nf`를 실제로 쓰는 이유는 면적·종횡비 등 **레이아웃 사유**이며 **Task 8에서 확정**한다.
