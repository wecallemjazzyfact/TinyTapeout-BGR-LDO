# BOOKKEEPING.md — gm/Id 예측 ↔ 회로 실측 대조 기록

위치: `designs/bgr_ldo/ldo/BOOKKEEPING.md`
목적: **이중 기장법(double bookkeeping)** — LUT 손계산과 회로 시뮬을 매 단계 대조한
기록. 이 표가 "Spice Monkey가 아니라 체계적 설계였다"는 **유일한 증거**다.

> **기재 규칙**
> 1. 예측·실측·조건(코너/온도/바이어스/geometry/추출법)을 항상 **셋 다** 적는다.
> 2. 예측이 틀렸으면 **틀린 채로 남기고** 원인을 적는다. 지우지 않는다.
> 3. 조건 없는 수치는 기재하지 않는다.
> 4. 행 번호는 추가만 하고 재사용하지 않는다.

스텝응답) → ×0.767(100 ns 엣지 sinc) = 52.1 mV vs 실측 31.6 mV. **경험적 인수 0.27**
(100 ns 엣지, 본 설계 한정). $Z_{out}$은 진단용, 스펙 판정은 과도가 정본.

**제약**: 부하 스위치 엣지 ≥ **1.5 µs 설계목표 / 1.0 µs 하드 하한**, **양방향**,
$I_{step}$ ≥ 1 mA인 싱크에 적용. 100 µA급(RO enable)은 제외.

**슬루 드라이버 검증(tt/27, ll/125)**: 엣지 1.85us 양방향(비대칭 0.69%), release Vmax 1.821/1.846V(마진 129/104mV), 인가 Vmin 1.719/1.705V (PG문턱 대비 여유 82.5/104mV), 로드레귤레이션 92uV@2mA, 폐루프AC 무간섭(PM 63.4/-0.1, GM 23.8/불변).


### 2.6 비율계량 (ratiometric biasing) — 적용 범위

같은 회로를 두 판으로 만들어 비교했다.
**판 A** = 이상 전류원 2.564228 µA 고정(대조군), **판 B** = 폴리 기준 전류원
(178유닛, L = 983.6154 µm, $I = V_{bg}/R_{poly}$). 판 B가 Task 6의 실제 구성이다.

**통합(실제 BGR 탭) 실측**: 트림 전 $g_{m,pass}/g_{m,EA}$ 스프레드 3.9% ($V_{ref}$가 ff에서 +4%로 $V_{out}$에 실림), 트림 후 ~0% (트림이 $V_{ref}$를 1.2 V로 고정 → 분자 소거 → 1.5×폴리비, $R_{poly}$는 `corner_factor` 공유로 소거). 거동원($F_{ref}$) 검증의 1.29%는 이상 $V_{bg}$ 고정 가정이라 트림 후 상태에 해당. 저항성분은 PDK 모델레벨(`corner_factor`)에서, 밴드갭 정확도성분은 트림이 소거 — 두 메커니즘 직교.

**① 공정(R/C 코너, 27 °C) — 작동한다**

$p_2/\text{UGF}$를 정하는 비 $g_{m,pass}/g_{m,EA}$:

| 판 | `ll` | `tt` | `hh` | 스프레드 |
| :--- | ---: | ---: | ---: | ---: |
| A | 10.53 | 9.12 | 8.13 | **29.60%** |
| **B** | 9.08 | 9.14 | 9.19 | **1.29%** (23배↓) |

추종 오차: `ll`/`tt`에서 $I_{div}$ ×1.1728 대 $g_{m,EA}$ ×1.1525 (**−0.2%**),
`hh`/`tt`에서 ×0.8785 대 ×0.8900 (**+0.0%**).

| 스프레드 | 판 A | 판 B | 감소 |
| :--- | ---: | ---: | ---: |
| GM @2 mA | 2.80 dB | **0.54** | 5.2배 |
| GM @4 mA | 2.86 | **0.44** | 6.5배 |
| PM @$I_{min}$ | 6.32° | **3.57** | 1.8배 |

최악값도 개선: GM 9.3 dB(판 A) → **10.3 dB**(판 B).

**② 온도(−40/27/125 °C) — 듣지 않는다**

| 스프레드 | 판 A | 판 B |
| :--- | ---: | ---: |
| PM @$I_{min}$ | 7.03° | 5.77 (1.2배) |
| PM @2 mA | 5.12° | **6.23 (악화)** |
| $g_{m,pass}/g_{m,EA}$ | **9.11%** | **9.11%** (동일) |

**원인**: $g_m = I_D(g_m/I_D)$이고 $(g_m/I_D) \approx 1/(nV_T)$는 절대온도 지배다.

| T | $V_T$ | $g_m/I_D$ (M1) |
| ---: | ---: | ---: |
| −40 °C | 20.091 mV | 20.18 |
| 27 | 25.865 | 17.60 |
| 125 | 34.310 | **14.46** |

이상 전류원인데도 $g_{m,EA}$가 ±20% 움직인다. 그런데 이 인자는 pass에도 동일하게
걸리므로 **비에서 이미 상쇄된다**: $g_{m,pass}/g_{m,EA} = I_{div}/I_{EA}$.
온도에서는 $R_{poly}$가 ±5%밖에 안 움직여 판 A조차 9.11%뿐이고, 판 B가 그것을 0으로
만들어도 PM은 거의 안 변한다.

**온도에서 실제로 움직이는 것은 $R_z$ 영점의 상대 위치다:**

| T | $R_z$ | $1/g_{m,pass}$ | 영점 $z$ | UGF | **$z$/UGF** |
| ---: | ---: | ---: | ---: | ---: | ---: |
| −40 | 7,548 Ω | 1,069 | 9.008 MHz | 3.318 | **2.71** |
| 27 | 7,817 | 1,261 | 8.903 | 2.773 | 3.21 |
| 125 | 8,211 | 1,628 | 8.866 | 2.160 | **4.10** |

$R_z$ 상승과 $1/g_m$ 상승이 상쇄되어 영점은 온도에 거의 불변인데 UGF만 54% 움직인다.
$z/\text{UGF} \propto 1/(g_{m,EA}R_z) \propto 1/(g_m/I_D) \propto T_{abs}$ — **남은 것은
절대온도 그 자체이며 비율계량으로는 잡을 수 없다.**

**③ 확정 서술** (문서 인용 시 이 문장을 쓴다)

> $I_{EA}/I_{div}$는 폴리/폴리 비라 **공정 산포에 불변**하며, 이것이
> $g_{m,pass}/g_{m,EA}$ 스프레드를 29.60% → 1.29%(23배)로, 중부하 GM 스프레드를
> 2.80 → 0.54 dB(5.2배)로 줄인다. **온도에는 적용되지 않는다** — 온도에서는
> $g_m/I_D \propto 1/V_T$ 인자가 pass·EA 양쪽에 동일하게 걸려 비에서 이미 상쇄되며,
> 잔여 PM 변동은 $R_z$ 영점이 UGF를 따라가지 못하는 데서 온다
> ($z/\text{UGF} \propto T_{abs}$, −40~125 °C에서 2.71 → 4.10).

**택하지 않은 대안**: $g_{m,EA}$를 온도 평탄하게 하려면 PTAT 전류가 필요하다
($g_m \propto I/V_T$이므로 $I \propto T$). BGR에 PTAT 가지가 있어 탭은 가능하지만,
그러면 $I_{EA}/I_{div}$ 비가 깨져 공정 산포 이득을 잃는다. **공정 대 온도의 교환**이며,
산포가 더 큰 축이므로 공정을 택했다.

### 2.7 측정 방법론 — 루프이득 (확정)

**Middlebrook 이중주입.** 궤환 루프의 한 점(분압 탭 ↔ EA 입력)에 0 V 전압원을 삽입해
DC는 닫아 둔 채, 전압과 전류를 각각 한 번씩 주입해 합성한다.

$$\frac{1}{1+T} = \frac{1}{1+T_v} + \frac{1}{1+T_i} \quad\Longleftrightarrow\quad T = \frac{T_vT_i-1}{T_v+T_i+2}$$

```
ntap ──[Vprb1 0V]── mid ──[Vprb2 0V]── nfb(EA 입력)
                      │
                    [Iprb]
                      │
                     GND
run 1: Vprb1 AC=1, Iprb AC=0 → T_v = -v(ntap)/v(nfb)
run 2: Vprb1 AC=0, Iprb AC=1 → T_i = -i(Vprb1)/i(Vprb2)
```

$Z_b/Z_f = k$일 때 $T_v = |A|+k$, $T_i = (1{+}|A|)/k$로 각각은 오염되지만 합성하면
정확히 $|A|/(1{+}k)$가 나온다($k$ 전 범위 오차 0, 수치 검증 완료).
Cadence `stb`(Tian/Kundert)와 같은 계열이며, Tian은 여기에 역방향 전달까지 포함한다.
전압원 극성이 반대여도 두 반전이 상쇄되어 식은 그대로 성립한다.

**폐기된 방법 2건** (#43 참조):

| 방법 | 결함 | 유효 상한 |
| :--- | :--- | ---: |
| 직렬 전압주입 | $Z_b/Z_f = 2\pi f C_{gg}R_{div}$, 35.8 MHz에서 1 | ~10 MHz |
| 기준입력 주입 | 차동쌍 비대칭 (Vinp 경로만 미러극 48.8 MHz 경유) | ~10 MHz |

$Z_{out}$ 직접 측정(`Iprobe` 구동점)은 근사가 없어 **진단용으로 유효**하나 루프이득이 아니다.
