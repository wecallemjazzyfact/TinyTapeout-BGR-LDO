## 2. IB_EA 바이어스 탭 성능

* **구성 소자**: `XXM_tap_top` (`pfet_g5v0d10v5` W20/L4 m1) + `XXM_tap_casc` (`pfet_g5v0d10v5` W10/L2 m1)
* **Compliance 범위**: $\pm 1\%$ 유효 전류 유지 구간 **`0 ~ 3.00 V`**, 역산 출력 저항 $R_{out} \approx 820\,\text{M}\Omega$ ($\Delta I / \Delta V = 1.22\,\text{nA/V}$)
  * 실측점: $V=0.5\,\text{V} \rightarrow 2.5646\,\mu\text{A}$ / $1.5\,\text{V} \rightarrow 2.5637\,\mu\text{A}$ / $2.0\,\text{V} \rightarrow 2.5632\,\mu\text{A}$ / $2.5\,\text{V} \rightarrow 2.5626\,\mu\text{A}$ / $2.8\,\text{V} \rightarrow 2.5618\,\mu\text{A}$
* **동작점 마진**:
  * $net\_tap = 2.9948\,\text{V}$
  * `tap_top`: $V_{DS} = 0.3051\,\text{V} > v_{dsat} = 0.1583\,\text{V}$ (포화 영역 마진 $147\,\text{mV}$)
  * `tap_casc`: $V_{DS} = 2.0446\,\text{V} > v_{dsat} = 0.1502\,\text{V}$
* **온도 특성**: $-40^\circ\text{C} = 2.6376\,\mu\text{A}$ / $27^\circ\text{C} = 2.5669\,\mu\text{A}$ / $125^\circ\text{C} = 2.4156\,\mu\text{A}$ (변동폭 $8.65\%$, $\text{TC} = -524\,\text{ppm}/^\circ\text{C}$)
  * 최악 코너 ($ss / -40^\circ\text{C}$): $2.6823\,\mu\text{A}$ (tt/27 대비 $+4.6\%$)
* **몬테카를로 산포**: $\sigma = 2.63\%$ ($N=100$, MM+PR), mean $= 2.57023\,\mu\text{A}$, $\text{corr}(V_{ref}, IB\_EA) = +0.772$ (상관 $2.03\%$ + 독립 $1.67\%$)

## 6. 저항 코너 구조 (`corner_factor` 메커니즘)

* **폴리 시트 수식**: $\text{sw\_sky130\_fd\_pr\_\_res\_high\_po\_rs} = \{325.0 + \text{corner\_factor} \times 45.0\} + \text{GAUSS}(0, 0.035, 1)$
* **종속 구조**: `corner_factor`는 트랜지스터 코너(`tt`/`ss`/`ff`)에 종속된 전역 변수임 (`parameters_res_high.spice`).
* **실측 $R_{2,\text{eff}}$ ($27^\circ\text{C}$)**:
  * `ff` 코너: $122.18\,\text{k}\Omega$ ($\text{corner\_factor} > 0 \rightarrow$ **저항 High**)
  * `tt` 코너: $115.75\,\text{k}\Omega$
  * `ss` 코너: $113.93\,\text{k}\Omega$ ($\text{corner\_factor} < 0 \rightarrow$ **저항 Low**)
* **의미**: $I_{B,\text{EA}}$와 $I_{\text{div}}$가 동일 폴리 저항을 공유하므로 `corner_factor`가 비에서 완전 소거됨. **비율계량이 PDK 모델 수준에서 보증됨**을 실증.
