### 3.1 저항 유닛 규약 (레이아웃 정합 요구에서 확정)

**(1) 매칭 쌍은 동일 유닛의 정수배로 구성한다.**

분압쌍이 서로 다른 길이(26.5447 / 54.2057)였던 이유는 컨택 헤드 저항 525.7 Ω를 상쇄하려고 L을 역산했기 때문이다. 이 보정은 헤드 저항이 설계값과 같을 때만 성립하며, 산포하면 비율이 깨진다.

동일 유닛이면 헤드가 유닛마다 하나씩 들어가 비율에서 소거된다:

$$\frac{R_2}{R_1} = \frac{2R_{unit}}{R_{unit}} = 2.0000$$

**유닛 길이·헤드 저항과 무관하게 비율이 정확**하다. 인터디지트(공통중심)도 동일 유닛일 때만 가능하다.

**실측 확인 (tt/27, ui_in=0111)**: 분압비가 **1.50006 → 1.500000**으로 떨어졌다. 그 40 ppm이 바로 헤드 보정 역산의 잔차였다. `n_rfmid`가 `FB_TAP`/2와 0.2 µV 일치해 두 하단 유닛이 동일함도 확인되었다. $V_{out}$은 1.790769 → 1.790770으로 1 µV만 변해 트림 코드 선택이 불변이다.

**(2) 격자 정렬 — 그리는 값이 0.005 배수여야 한다.**

magic 대화상자 Length가 0.005 µm 격자로 절사되므로, 모델 `L`이 아니라 **그리는 값 $u$**가 격자 위여야 한다.

| nx | $L_{model}$ | $u$ 산출 |
| ---: | :--- | :--- |
| 1 | $u$ (보정 없음) | $u = L$ |
| 8 | $8u - 7 \times 0.0386$ | $u = (L + 0.2702)/8$ |

정렬 결과:

| 소자 | nx | $u$ | $L_{model}$ |
| :--- | ---: | ---: | ---: |
| `XRF1`/`XRF2a`/`XRF2b` | 8 | 3.350 | 26.5298 |
| `XRz` | 1 | 15.480 | 15.480 |
| `XR_snk1`/`XR_snk2` | 1 | 29.800 | 29.800 |
| `XR_slew1`/`XR_slew2` | 8 | 78.190 | 625.2498 |
| `XR_nb2`/`XR_pb1c`/`XR_pb2` (ea_fc) | 8 | 37.930 / 30.320 / 10.960 | 303.1698 / 242.2898 / 87.4098 |

**(3) nx=1 셀 기하 (레이아웃 실측 확정, nx=8과 다름)**

| 항목 | nx = 1 | nx = 8 |
| :--- | :--- | :--- |
| 폭 | **W** | 8.880 (W=0.69) |
| 높이 | **L + 4.160** | $u$ + 2.680 |
| 단자 위치 | **상·하 양단** | 양쪽 하단 |
| $L_{eff}$ | **$u$** (보정 없음) | $8u - 7\times0.0386$ |

검산: `XRz` 15.480 + 4.160 = 19.640 ✔ / `XR_snk` 29.800 + 4.160 = 33.960 ✔

`res_high_po_5p73`의 굴곡 보정 계수는 nx=1이라 **불필요**하다. nx>1이 필요해지면 N별 2점 실측을 선행할 것(외삽 금지).

## 4. MiM 커패시터 물리 제약 및 적층 전제 폐기

### ★ MiM 적층 불가 — TinyTapeout met5 금지와 충돌

`sky130A.tech` 원문:
```text
mimcc  mimcap  metal4      <- cap_mim_m3_1 상판 컨택 -> met4
mim2cc mimcap2 metal5      <- cap_mim_m3_2 상판 컨택 -> met5 전용
layer mim2cc VIA4
```

`cap_mim_m3_2`는 상판을 **met5로 뽑는 것 외에 결선 수단이 없습니다.** TinyTapeout은 met5를 자사 전원 그리드용으로 금지하며(`tt/precheck/tech_data.py`의 `forbidden_layers`에 `met5.drawing`/`met5.pin`/`met5.label`), GDS에서 발견되면 precheck가 즉시 실패시킵니다.

➔ **`cap_mim_m3_1` 단층만 사용 가능 (2.0 fF/µm²).**  
기존 "적층 시 4.0 fF/µm²" 서술은 **오류였으며 폐기**합니다.

> 💡 **넷리스트 영향 검증**  
> 스키매틱의 캡이 전부 `cap_mim_m3_1`이고 `m3_2`는 한 개도 쓰지 않았습니다. 즉 **시뮬레이션은 처음부터 단층 전제로 돌았고 회로 수치는 전부 유효**합니다. 정정 대상은 문서뿐입니다.

### 유닛 캡 실측치 (레이아웃 확정)

조건: magic 8.3.664, gencell 생성, `.mag` 전층 덤프, magscale 1 2

| 항목 | 값 |
| :--- | ---: |
| 요청 W=L | 18.3147 µm |
| **실제 `mimcap`** | **18.310 µm** (magic이 0.005 격자로 절사) |
| **셀 외곽(metal3 하판)** | **20.470 × 18.710 = 382.99 µm²** |
| metal4 상판 | 17.920 µm 정사각 |
| 순수 캡 면적 대비 오버헤드 | +14.2% |

용량 모델 (gencell 파라미터 실측: `carea 2.00 cperi 0.19 val 684.797`):

$$C = 2.00 \times W\cdot L + 0.19 \times 2(W+L) \quad [\text{fF}, \mu\text{m}]$$

검산: $2.00 \times 335.428 + 0.19 \times 73.259 = 684.78 \approx \text{val } 684.797$ ✔

**W=L=18.310 기준 유닛 용량 = 684.43 fF**

**스키매틱 정정**: 캡 4종의 W/L을 `18.3147` ➔ **`18.310`**으로 변경 완료. magic 격자 절사와 LVS property 대조를 맞추기 위함이며 용량 영향 $-0.05\%$로 무해합니다. RO 부하캡(4.27/4.17)과 $C_{boost}$(5)는 격자에 맞아 변경 없습니다.

### 확보 가능 슬롯

1×2 타일(145.36 × 225.76 µm)에서 BGR 무수술 기준 **6열 × 7행 = 42슬롯 = 28.75 pF**.  
7열은 전원 스트라이프 코리도를 더하면 149.2 µm로 타일 폭을 초과합니다.
