## 7. 트림 코드 — ★ LUT 순서 필수 원칙

이진 code는 단조가 아님:
```text
code 31 = 011111  ->  1.774496 V
code 32 = 100000  ->  1.783678 V     (+9.18 mV 역전)
```
- **원인**: TRIM5(18,198 Ω) > 하위 5비트 합(17,886 Ω) = **312 Ω 초과**
- **해법**: 이진 code 대신 **전압 내림차순 rank**로 트림 이동:
```text
LUT 파일 : ldo/lut6.txt (rank code V, 63 엔트리)
알고리즘 : rank_new = rank_cur + round((V - 1.800) / 8.377mV)
```

### AC 이중주입(Middlebrook) 계산식
```text
Tv = -v(x1.FB_TAP)/v(x1.FB_TAP_PRB)      (tv 덱)
Ti = -i(v.x1.vprb1)/i(v.x1.vprb2)        (ti 덱: 전류비)
T  = (Tv*Ti - 1)/(Tv + Ti + 2)
```
